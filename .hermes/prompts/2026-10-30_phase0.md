## Project context

"Plexi Box" is a standalone digital guitar stompbox on a Raspberry Pi Pico 2 (RP2350A,
dual Cortex-M33, hardware single-precision FPU, ARMv8-M DSP extensions). It models two
classic British tube preamplifiers (Marshall 1959 Super Lead "Plexi" and Marshall JCM800
2203), a passive FMV (Fender-Marshall-Vox) interactive tone stack, a power-amp presence
filter, and a Marshall 1960B 4x12 cabinet impulse response via direct-form 1024-tap FIR
convolution. 48 kHz, 24-bit audio. No neural network models — the preamp is modeled
analytically (tanh-based triode waveshapers with bias and cathode sag).

## Architecture decisions already made — do NOT re-litigate or change them

1. Toolchain: PlatformIO with the community platform
   `https://github.com/maxgerhardt/platform-raspberrypi.git`, framework `arduino`,
   `board_build.core = earlephilhower`, board id `rpipico2`.
2. I2S clocking: the **PCM1808 ADC is the bus MASTER** (it owns a 12.288 MHz crystal and
   drives BCLK at 64xfs = 3.072 MHz and LRCK at 48 kHz). The RP2350 is a SLAVE on BCLK/LRCK,
   and the PCM5102A DAC is also a slave on the same two clock lines (its SCK pin is tied to
   GND so it uses its internal PLL). One single clock domain, no drift.
3. Six potentiometers are read through a 74HC4051 analog multiplexer into ONE ADC channel.
4. NEVER enable the RP2350 internal pull-DOWN resistors (documented silicon erratum: the pin
   latches low after the first read). Use internal pull-UP or external resistors.
5. Core 0 is audio DSP only. Core 1 owns all UI, control and coefficient calculation.
6. Target overclock 250 MHz with core regulator 1.20 V, with a documented fallback to
   200 MHz. Phase 0 must be able to prove which clock actually came up.

| Function | GPIO | Notes |

| I2S BCLK (from PCM1808 BCK) | GP21 | input, 64xfs = 3.072 MHz |
| I2S LRCK / WS (from PCM1808 LRCK) | GP22 | input, 48 kHz |
| I2S DOUT (to PCM5102A DIN) | GP23 | output, any pin is allowed |
| Pot mux common output (analog in) | GP26 | ADC0, 100 nF to AGND |
| Pot mux select S0 / S1 / S2 | GP6 / GP7 / GP8 | outputs |
| Footswitch (channel toggle) | GP14 | to GND, INPUT_PULLUP, 20 ms debounce |
